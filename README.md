# CityTailor

**CityTailor** is a native iOS app that creates personalized city travel plans based on your interests, travel dates, and weather conditions.

## 🌍 About the Project

Many travel apps are too generic. TravelPlanner aims to be smart, personal, and offline-capable.

This app lets users:
- Select a city and travel date(s)
- Choose their interests (e.g. history, food, nature, art)
- Receive a day-by-day itinerary with recommended spots
- Automatically adapt to weather and opening hours
- Save plans offline for no-internet scenarios

## 📦 Core Features

- Native iOS app (Swift + SwiftUI)
- Apple Maps integration
- Apple WeatherKit for real-time weather
- Local storage via Core Data for offline use
- Dynamic routing suggestions (walk, transit, etc.)
- Optional notifications/reminders

## 🔧 Planned Architecture

- View layer: SwiftUI + MVVM
- Data layer: WeatherKit, Apple Maps API, custom Points of Interest dataset
- Storage: Core Data
- Offline-first approach
- No backend (initially)
